What is n8n ?
Workflow automation tool
-All workflows are json Based
-Uses nodes and connections
-Easy to Understand and Debug

Components of N8N 
Nodes:- Building blocks (e.g., Gmail, HTTP Request, AI Agent).
Workflows:- Collection of nodes connected together.
Credentials:- Securely store API keys and logins.


Nodes Categories:-
1. Trigger nodes:- How workflow starts
2. Action nodes:- Perform tasks
3. Logic Nodes:- Add conditions, branch or loop
4. Data Nodes:- Transform, Merge, Split, map data
5. Connections:- Define data flow between nodes
6. Execution Log:- Tracks workflow executions success/failure

Workflow Components
1. Triggers:- Star the workflow e.g. new email, On schedule, Manual etc)
2. Actions:- Steps to execute(E.g. reply to email)
3. Data Flow:- How data moves/pass from one step to another



Workflow is sequence of actions
workflow types-
A. Linear workflow:- Sequential execution of nodes
B. Non-linear:- Ai in loop for decision making

E.g. of Linear Workflow

1. Getting customer feedback(Positive, Negative,Neutral) alongwith more details
